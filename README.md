# Prompt Panel

SillyTavern의 프리셋, 월드인포, 캐릭터카드를 한 패널에서 열람·번역·검색·내보내기 할 수 있는 확장입니다.

## 주요 기능

### 데이터 로드
현재 사용자의 SillyTavern에 등록된 **프리셋, 월드인포, 캐릭터카드**를 패널에서 직접 로드해서 보여줍니다.

### 번역
- 토글/엔트리/필드 단위 번역, 개별 재번역
- 번역 캐시는 브라우저 IndexedDB에 저장 (SillyTavern 설정 파일에 저장하지 않음)
- 지원 프로바이더: OpenAI, Claude, Google AI Studio (MakerSuite), Vertex AI, OpenRouter, DeepSeek, Mistral, Groq, Cohere, xAI, Z.AI (GLM)
- **📛 제목 번역**: 제목만 빠르게 번역합니다. 여러 제목을 한 요청으로 묶어 보내므로 토글이 수백 개인 프리셋도 빠르게 훑어보고 어떤 토글을 본문까지 번역할지 미리 정할 수 있습니다. 본문 번역과 별도로 저장되므로 나중에 ✦번역을 눌러도 본문 번역이 정상 실행됩니다.
- **👀 제목 보기**: 패널에 보이는 토글 제목을 번역본으로 전환합니다. 다시 누르면 원어로 돌아갑니다. 표시만 바꾸며 데이터는 변경되지 않습니다.
- **번역 언어 직접 지정**: 드롭다운의 `⚙️ 직접 입력`을 고르면 원하는 언어를 자유롭게 입력할 수 있습니다. 목록에 없는 언어도 모두 사용 가능하며, 입력한 값이 번역 요청에 그대로 쓰입니다 (영어 언어명 권장, 예: French).
- **월드인포 키워드 번역**: 엔트리의 키워드(Primary Keywords)와 보조 키워드(Optional Filter)가 번역 본문 앞부분에 함께 표시되며, JSON 내보내기 시 각각 `key`, `keysecondary` 필드로 되돌아갑니다.
  - 기본 키워드는 원본을 유지한 채 번역본이 **추가**되므로 원문·번역문 어느 쪽으로 대화해도 발동합니다.
  - 보조 키워드는 엔트리의 Logic 설정에 따라 처리가 갈립니다. `AND ANY`·`NOT ANY`는 기본 키워드와 같이 병합되지만, `AND ALL`·`NOT ALL`은 조건 자체가 "전부 일치"라서 항목을 추가하면 엔트리가 발동하지 않게 됩니다. 이 두 경우에는 병합 대신 **번역본으로 교체**합니다. 따라서 해당 엔트리는 번역 언어에서만 정상 동작합니다.
- **월드인포 엔트리 정보 표시**: 엔트리를 펼치면 발동 방식(🔵상시 / 🟢키워드 / 🔗벡터), position, depth, order, trigger%가 작은 글씨로 표시됩니다. 정보 제공용이며 번역 대상이 아닙니다.
- **요청 속도 조절**: 확장 드로어에서 제목 번역 묶음 개수와 요청 간 대기 시간(ms)을 조절할 수 있습니다. API 분당 요청 한도(예: Vertex AI)에 걸린다면 대기 시간을 늘리세요. (1000ms = 1초)
- 프로바이더별 샘플링 파라미터 개별 설정

### 검색
원문과 번역문 양쪽 모두에서 키워드 검색이 가능합니다. 일치하는 부분은 패널에서 하이라이트로 표시됩니다.

### 토큰 수 계산
로드된 항목 전체 토큰 수, 선택한 토글의 합계 토큰 수가 실시간으로 표시됩니다.

### 복사 및 내보내기
각 탭(프리셋/월드인포/캐릭터) 상단 우측에 3개의 아이콘 버튼이 있습니다.

- **복사**: 클립보드로 복사
- **TXT 내보내기**: 텍스트 파일로 저장
- **JSON 내보내기**: SillyTavern 호환 JSON 파일로 저장

#### 복사 / TXT 내보내기
토글을 일부만 선택해서 그 부분만 복사·내보낼 수 있습니다. 실행 시 **원문만 / 번역문만 / 둘 다** 중 하나를 선택할 수 있고, 번역이 없는 항목은 번역문 모드에서 `(번역없음)`으로 표시됩니다.

#### JSON 내보내기
- **프리셋**은 토글 선택 여부와 관계없이 **항상 전체**를 내보냅니다 (구조가 깨지지 않도록 보장). 프리셋에 동봉된 **정규식과 기타 확장 설정도 함께 내보내집니다**.
- **월드인포**는 토글을 일부만 선택했다면 선택된 엔트리만 내보냅니다.
- **캐릭터카드**는 필드를 일부만 선택했다면 선택된 필드의 번역만 적용해서 내보냅니다. **임베디드 월드북(`character_book`)이 카드 안에 있다면 함께 내보낼지 묻는 창**이 뜨고, 포함을 선택하면 원문 그대로 동봉됩니다.
- 토글 제목도 번역되며, JSON 내보내기 시 번역된 제목은 토글의 이름 필드(프리셋의 `name`, 월드인포의 `comment`)에 들어갑니다.

#### JS Runner 제목 번역 스크립트
프리셋 탭과 월드인포 탭에서 JSON 내보내기를 누르면 형식 선택창이 뜹니다. **JS Runner 제목 번역 스크립트**를 고르면 SillyTavern 본 화면에서 제목이 번역본으로 보이게 해주는 스크립트가 생성됩니다. JS-Slash-Runner 확장에 임포트해서 사용하세요.

- 프리셋: 프롬프트 토글 이름을 번역본으로 표시합니다.
- 월드인포: 엔트리 제목 위에 번역본을 힌트로 덧붙입니다. 입력창 값은 절대 건드리지 않으므로 월드인포 데이터가 바뀔 위험이 없습니다.
- 화면 표시만 바꿉니다. JS Runner에서 스크립트를 끄면 즉시 원상복구됩니다.

#### 파일명
`{소스이름}_{번역언어}.{확장자}` 형식으로 자동 생성되어 브라우저의 기본 다운로드 폴더에 저장됩니다.

### UI
- **플로팅 아이콘**: 옵션으로 활성화 시, 화면에 상시 떠 있는 드래그 가능한 아이콘으로 어디서든 패널을 열 수 있습니다
- 프리셋/월드인포/캐릭터 탭
- 패널 헤더의 새로고침 버튼: ST에 새로 추가/삭제된 항목을 즉시 패널에 반영 (번역 캐시는 보존)
- 원문/번역문 글자 크기 조절
- 테마 6종: Dark, Light, Pink, Mint, Orange, Blue
- 상태 표시줄에 현재 설정된 번역 모델명이 함께 표시됩니다

### 지원 언어
한국어, 영어, 일본어, 중국어 간체, 중국어 번체, 폴란드어, 커스텀 추가 가능.


## 참고 사항

- 모든 내보내기는 원본 데이터를 깊은 복제(deep clone)한 뒤 복제본만 수정하므로, **원본 프리셋/월드인포/캐릭터카드는 절대 변경되지 않습니다.**
- 캐릭터카드 JSON 내보내기는 V3 spec에 따라 `data.*` 경로를 정본으로 사용하며, V1 호환용 최상위 중복 필드는 비워서 파일 크기를 최소화합니다. SillyTavern은 import 시 `data.*`를 우선 사용하므로 호환성에 영향이 없습니다.


두 확장 모두 AGPL-3.0 라이선스로 배포됩니다.
